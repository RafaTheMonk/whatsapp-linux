## O que muda na 1.0.4

- **Electron 44.5.1** (era 44.3.0): traz as correções de segurança do Chromium, do V8 e do ANGLE publicadas desde a 1.0.3. O app em si não mudou.
- **Pacotes para ARM64** (Raspberry Pi 4 e 5, notebooks ARM): AppImage, `.deb` e `.tar.gz` com `arm64` no nome. São gerados e conferidos num runner ARM nativo, mas ainda não foram testados num aparelho ARM. Se usar, conte como foi numa issue.
- **Build feito pelo GitHub Actions**, numa máquina limpa, com atestação de procedência: dá para conferir que o arquivo baixado saiu deste repositório e deste commit com `gh attestation verify <arquivo> --repo RafaTheMonk/whatsapp-linux`.
- O `.tar.gz` passa a levar a arquitetura no nome: `whatsapp-linux-1.0.4-x64.tar.gz` e `whatsapp-linux-1.0.4-arm64.tar.gz`.

## Qual arquivo baixar

| Sua distro | x86_64 (maioria dos PCs) | ARM64 |
|---|---|---|
| Ubuntu, Mint, Debian, Pop!_OS | `whatsapp-linux_1.0.4_amd64.deb` | `whatsapp-linux_1.0.4_arm64.deb` |
| Fedora, Arch, openSUSE, Manjaro, outras | `WhatsAppLinux-1.0.4-x86_64.AppImage` | `WhatsAppLinux-1.0.4-arm64.AppImage` |
| Prefere descompactar na mão | `whatsapp-linux-1.0.4-x64.tar.gz` | `whatsapp-linux-1.0.4-arm64.tar.gz` |

## Instalar

```bash
# Debian e derivados
sudo apt install ./whatsapp-linux_1.0.4_amd64.deb

# AppImage
chmod +x WhatsAppLinux-1.0.4-x86_64.AppImage
./WhatsAppLinux-1.0.4-x86_64.AppImage
```

O AppImage e o `.tar.gz` oferecem criar o atalho no menu de aplicativos na primeira execução.

## Conferir antes de rodar

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
gh attestation verify WhatsAppLinux-1.0.4-x86_64.AppImage --repo RafaTheMonk/whatsapp-linux
```

Detalhes, privacidade e o que fazer se não abrir: [DISTRIBUICAO.md](https://github.com/RafaTheMonk/whatsapp-linux/blob/main/electron/DISTRIBUICAO.md).
