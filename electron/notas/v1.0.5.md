## O que muda na 1.0.5

- **Clicar na notificação abre o app.** Antes, com a janela fechada na bandeja, o clique não fazia nada. Agora a janela aparece, inclusive se estiver minimizada.
- Electron continua no 44.5.1, o mesmo da 1.0.4.

## Qual arquivo baixar

| Sua distro | x86_64 (maioria dos PCs) | ARM64 |
|---|---|---|
| Ubuntu, Mint, Debian, Pop!_OS | `whatsapp-linux_1.0.5_amd64.deb` | `whatsapp-linux_1.0.5_arm64.deb` |
| Fedora, Arch, openSUSE, Manjaro, outras | `WhatsAppLinux-1.0.5-x86_64.AppImage` | `WhatsAppLinux-1.0.5-arm64.AppImage` |
| Prefere descompactar na mão | `whatsapp-linux-1.0.5-x64.tar.gz` | `whatsapp-linux-1.0.5-arm64.tar.gz` |

## Instalar

```bash
# Debian e derivados
sudo apt install ./whatsapp-linux_1.0.5_amd64.deb

# AppImage
chmod +x WhatsAppLinux-1.0.5-x86_64.AppImage
./WhatsAppLinux-1.0.5-x86_64.AppImage
```

O AppImage e o `.tar.gz` oferecem criar o atalho no menu de aplicativos na primeira execução.

## Conferir antes de rodar

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
gh attestation verify WhatsAppLinux-1.0.5-x86_64.AppImage --repo RafaTheMonk/whatsapp-linux
```
